# Neue Homepage und Mitarbeit
2025-08-16

Das ist das Projekt für die deutschsprachige Godot-Community Homepage.

Jeder der Mitglied auf dem Dicord Server der deutschsprachigen Godot-Community ist, kann helfen den Inhalt dieser Homepage zu gestalten.

## Inhalte in Markdown
Inhalte/Texte werden in einem Markdown-ähnlichen Schreibweise geschrieben. Dieser ist leicht zu erlernen. Ein weiterer Vorteil ist, das ein Text sehr einfach in diese **LiDoc** Schreibweise umgewandelt werden kann, indem wenige einfache Parameter hinzugefügt werden.

Zum Beispiel für Überschriften kann durch voranstellen vom Raute Symbol(#) ein Text in eine Überschrift umgewandelt werden.
so wird aus
```md
Das ist eine Überschrift
```
durch voranstellen von zwei (##) eine **H2** Überschrift.
```md
## Das ist eine Überschrift
```



Die Seiten werden mit dem **LiDoc** Javascript Framework im Browser generiert und Angezeigt.
